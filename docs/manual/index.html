Chapter 1Getting started

ProwdCAD runs in Chrome or Edge. There is nothing to install.

  1. Open prowdcad-v2.html in Chrome or Edge. It works offline. Keep the file somewhere permanent, for example a ProwdCAD folder on your desktop.
  2. The first time, ProwdCAD opens with a 400 × 600 mm practice block in sizes XS–XL. To start real work use File ▸ New (Ctrl+Alt+N).
  3. In the New style dialog type the style name, the size range separated by commas (S, M, L, XL, 2XL) and the base size (M). Untick Start with a rectangle block if you want an empty sheet.
  4. Save with Ctrl+S. A style is one .prowd.json file that holds every piece, size and grade rule.
DevelopersFrom the GitHub repo (branch v2): npm install, then npm run dev. npm run build:single rebuilds the one-file version.

Select only selects

The Select tool (V) never moves anything. It picks points, segments, internal lines, notches, drills, darts and pieces, and the selection stays while you run commands, undo, switch sizes or switch tools. You move things with the Move tools (Chapter 6), which take the current selection straight away.

Every tool works the same way: Enter finishes, Esc cancels, Backspace removes the last point you placed. A quick tap of Space in a Move tool jumps back to Select with the selection kept; tap it again to return to the Move tool. F1 lists every shortcut.

Chapter 3Units and typing values

ProwdCAD stores everything in millimetres and calculates in full precision. Choose what you see in the Unit box of the status bar: mm, cm or inch (inch can show fractions in 8ths, 16ths, 32nds or 64ths).

  5. Shoulder point: dX 9, dY 12, Equal X and Y. Copy it, select the neck point and the centre-front neck (Shift+click), then Paste Y only.

Select a piece and press Ctrl+I for sew length, cut length and area in every size. Then File ▸ Export ▸ PDF (Ctrl+P) with Pieces: All pieces and Sizes: All sizes. For this style that gives 32 A4 pages at 1:1.

Chapter 5Drawing pieces

A piece has a sew line and a cut line. You draw and edit the sew line; the cut line is calculated from it and the seam allowances, so it is always correct after an edit.

P

Pen: new piece

Click = corner, click-drag = smooth point with handles, Ctrl+click = curve point, Shift = horizontal/vertical/45°. Click the start point or press Enter to close.

R

Rectangle, circle, polygon

Drag to draw, or click once for a dialog with exact sizes. A circle can be set by diameter or by perimeter.

I

Internal line

Start inside a piece. Double-click or Enter ends a line, clicking the start closes a shape. Right-click gives an exact length and mirror options. An end you put on the outline is locked to it (see below).

Shift+T

Trace

Click around existing lines and points to make a new piece from them.

Snapping. While you draw or move, the cursor snaps to, in this order: a point, the intersection of two lines, the midpoint of a segment, the perpendicular foot from where the move started, a guide, and the grid (View ▸ Snap; Ctrl+Shift+' toggles grid snap). The Move tools show a small label (pt, int, mid, perp) next to the target. Hold Alt to switch snapping off for one drag.

Grade points and curve points. Grade points (squares) are corners and carry grading. Curve points (circles) shape the curve between them. A curve point without grading of its own follows its neighbouring grade points in the other sizes, so it moves when they move. To keep it where it is, select it and use Point ▸ Pin curve point (keep position): it then gets its own grading and shows a dot in the middle. Point ▸ Unpin makes it follow again. Use as few curve points as give the shape you want.

Internal lines locked to the outline

An internal line can be locked to a segment of the sew line, so it keeps its place when that segment moves, changes length, gets new points or is graded. The lock is worked out again after every edit, in every size; nothing has to be updated by hand. A locked line shows a small padlock (its tooltip says what it is locked to), and each attached end a dashed ring.

LockWhat stays fixedUse it for
Endpoints on segmentEach end that lies on the outline stays on its segment: at the same proportion of the segment (default), or at the same distance from the segment's start or end. The points in between keep their own position.Yoke and style lines, princess lines, pocket openings that start on a seam.
Parallel to segmentThe whole line is the exact offset of the segment (positive = inside), from one position along it to another. It is re-drawn when the segment changes shape.Topstitching, facing lines, placement lines.
Follow pointThe line (open or closed) moves with one sew point, in every size.Patch pockets, labels, appliqué shapes.
  1. While drawing: with the Internal line tool (I), an end you snap onto the outline is locked to its segment automatically (option Lock ends to outline in the strip under the menus, also in Edit ▸ Preferences; on by default, like attach in CLO / AccuMark).
  2. Later: select the line and set Lock in the Inspector, or right-click it ▸ Lock internal to segment… (Segment ▸ Lock internal to segment…). ProwdCAD uses the segment under each end (Endpoints), under the line (Parallel) or the nearest grade point (Follow); Pick segment… / Pick point… lets you click another one. The Inspector also sets how a position is kept (Proportional, Distance from segment start, Distance from segment end) and, for Parallel, the offset and the From / To range.
  3. Unlock: right-click the line ▸ Unlock internal line, or Unlock in the Inspector. The line keeps its shape and its points move freely again.
Moving locked linesA locked point cannot be moved on its own (Move Point says why); move the outline instead, or unlock. The free middle points of an Endpoints line still move, and Move Line moves a Follow line as a whole (it then follows the point from its new place). A point connection (Piece ▸ Connections) wins over the lock for that point. If a segment end point is deleted, its lock is removed and the line stays where it is.

Chapter 6Points and segments

Select what you want to change (Chapter 2), then press a Move key. The Move tool takes the selection straight away; or start the tool first and click the point, line or piece. Each move is one undo step, and the moved object stays selected so you can move it again.

KeyToolWhat moves
GMove PointSingle (default): exactly the point you grab, with its own handles. Nothing else is stored differently. Other modes (Tab cycles, or Point ▸ Modify Points): Smooth (the curve points between the two tacks blend; drag a tack to another point to change the range), Horizontal, Vertical, Along line (slides on its own line), Group (every selected point by the same amount).

Moving a point

  1. Drag it: press on the point and drag. Or click it, then click the new spot (AccuMark style). Clicking the picked-up point again on the same spot puts it back.
  2. Type it: with a point picked, type a number (or right-click). The input box opens next to the cursor with dX dY, Distance ∠ and Absolute X Y. Fractions and units work: 1 1/8, 2cm. Tab = next field, Enter or right-click = OK, Esc = cancel. Enter with nothing typed repeats the last move. Note: 12,5 in the first field means dX 12, dY 5; the box says so. For a decimal type 12.5.
  3. Shift = horizontal / vertical / 45°, Alt = no snap, arrow keys nudge (Shift = ×10), Backspace undoes the pick, Esc when idle goes back to Select.
"The other points moved"Move Point · Single never changes another point's stored position. Two things can still look like it: (1) an internal point tied to the moved point by a point connection (Piece ▸ Connections) follows it and is marked "connected"; (2) curve points without their own grading follow their neighbours in the other sizes. While you drag a grade point, ProwdCAD draws the old curve dashed, rings the curve points that follow (labelled "follows") and says so in the status bar. To fix them in place, move them with Move Point ▸ Single, or select them and use Point ▸ Pin curve point.

On a size other than the base (amber badge) a move changes only that size's grading; the base and the other sizes stay where they are. The Inspector X / Y boxes do the same thing as Move Point, connections included.

Cut Point

The Cut Point tool (X, its own palette button) adds points to a sew line or an internal line without changing its shape, like CLO's Add Point / Split Line.

  1. Hover a line. A dot slides along it. The segment under the cursor (grade point to grade point) is drawn in two colours: blue from the segment start (marked start), orange to its end, each with its length. Next to the dot and in the status bar you see the distance from the start, the distance to the end and the percentage. Hold Shift to round to 5 mm (1/8" in inches).
  2. Click to add a grade point there. Ctrl+click adds a curve point. The new point is selected, so you can move it straight away.
  3. Exact values: right-click the line, or just type a number while hovering. The input box offers From start, From end, Ratio %, Divide (N equal parts adds N − 1 points) and Every (a point every X from the start). The points appear on the line while you type; Enter or right-click = OK, Esc = cancel. Fractions work: 1 1/8.

Options in the strip under the menus: Curve point, Notch (a notch on every new point) and Zero grade. By default the new points grade proportionally between their neighbours. On a graded size (amber badge) the lengths are measured on that size and the point is placed at the same ratio of the base line. Each insertion is one undo step.

Chapter 7Seams and the cut line

Each piece has a default seam set when you create it. To change part of the outline press S, click the first point of the run and then the last point, and type the value. Positive values go outward, negative inward. Double-click a piece to set the whole piece.

Corners

Right-click a corner point and choose Corner type:

TypeUse it for
MiterThe default: the two seam edges meet.
BoxedSquare corners, e.g. a seam that is pressed open at a hem.
Turn-backHems and facings that fold back: the corner is mirrored so it lies flat when folded.
AngledA straight chamfer across the corner.
ManualSeam ▸ Manual seam angle: click two points to trim the corner by hand.

Lock grading (Inspector, piece) copies the base size's corner shape to every size, so a hem corner looks identical from S to 2XL. The copy is refreshed after every edit of the sew line, its seams or its sizes.

Seams follow your edits

The seam allowance belongs to the segment (grade point to grade point), and the cut line is calculated again after every change, in every size. When you change the segments themselves, the seams go with them:

  • Adding a point on a segment (Cut Point, Add point, Divide, notch Add points, a curve point made a grade point) splits it into two segments that both keep its seam. Corner types stay on the original corners.
  • Removing a grade point (Delete, grade → curve, Points cleanup) joins two segments; the joined segment keeps the seam of the first one, as in AccuMark.
  • Moving, re-shaping or setting the length of a segment never changes its seam.
  • New edges from Slash, Cut along internal, Cut parallel strip and Fold get the seam you type in the dialog (or the piece default; a fold edge gets 0). Shapers, Round corner, Swap and Join keep the seam of the segment they replace. Darts, pleats and slash & spread keep the seam of the segment they open.

Chapter 8Notches, drills, text

Press N and click a sew line or internal line. Choose how the notch is placed:

PlacementBehaviour when the seam changes
On pointMoves with that grade point.
From previous / from nextKeeps its distance from that point. Set a different distance per size in the notch grid.
Percent of segmentStays at the same percentage, e.g. 30% stays 30% when the seam gets longer.

Notch types: slit, T, V, U and castle, each with depth, width and a cut or draw setting (Notch ▸ Notch setup). Click an existing notch to open the notch grid, where you can type per-size distances, fill all sizes, extend an increment, or paste a column from Excel.

Press D for drill holes, buttons and buttonholes; Notch ▸ Multi buttons spaces buttons evenly between two points. Press T for text. Notch ▸ Binding generator (Ctrl+Alt+B) builds a bias binding strip from seams you click across several pieces, notches included.

Chapter 9Darts, pleats, fullness

These stay editable after you create them: you can close, reopen, move or delete them without losing the original outline. All three tools work the same way: the status bar tells you the next click, you see the finished result before you click (cut line and dart cap included), right-click or type a number for exact values, Esc cancels, Backspace goes back one click, and each object is one undo step. Right-click an existing dart, pleat or slash line for its menu.

Shift+D

Dart

Click leg A, click leg B on the sew line, then click the apex inside the piece. Legs are made equal automatically.

Shift+L

Pleat

Click the start and end of the first pleat line, move to where the last pleat goes, click. Knife, box or inverted box; tapered depths.

Shift+U

Slash & spread

Click the slash point on the hem, then the hinge, move the cursor to open the slash, click. One slash or several, rotate or parallel.

X

Cut Point

Add points to a line at an exact length, a ratio or in equal parts. See chapter 6.

Dart

  1. Leg A: press Shift+D and click the sew line where the first leg goes.
  2. Leg B: move along the line; the opening is highlighted with its width. Click the second leg (Shift rounds the width), or type the width.
  3. Apex: move inside the piece. You see the dart, its depth and both leg lengths; ✓ equal means the legs match. Shift keeps the apex on the centre line. Click to finish, or right-click for exact Width · Depth, Width · Leg length or Width · Angle.

Equal legs (on by default, in the strip) slides both legs along the seam until they are the same length, as AccuMark's Fix Dart does. Fold to leg B sets which way the intake is pressed; the dart cap on the cut line follows it.

To reshape a dart, press on its apex and drag, with Move Point (G) or the Dart tool. On the base size the legs stay equal; on another size only that size's apex moves. Right-click a dart for Edit dart (width, depth, fold, drill in one dialog), Flip fold, close / reopen, cutting dart, Pivot transfer (move the dart around the apex; 100% moves all of it, 50% splits it in two), rotate around a centre, multi darts, copy / paste and remove. Pivot transfer, rotate and multi darts show the result while you type the amount. The Inspector lists width, depth and both legs for every size.

Pleat

  1. Choose Knife, Box or Inverted box in the strip. Open now and Notches are on by default.
  2. Click the start of the first pleat line (e.g. on the waist), then its end (e.g. on the hem). Alt+click the end to add only the pleat line and set the values later in the Inspector.
  3. Move the cursor to the side the pleats go. The distance sets where the last pleat line lies; the pleats are spaced evenly up to it. + / − change the number of pleats, F flips the fold, L lets you click a separate last line instead (for flared panels). Click to create.
  4. Right-click for exact values: number of pleats, depth at start, depth at end (different values make a tapered pleat) and the interval between pleats.

A knife pleat uses 2 × depth of fabric, a box or inverted box pleat 4 × depth. Blue arrows on the pattern show the fold direction: knife pleats point the way the fold is pressed, box pleats point away from the centre, inverted box pleats point toward it. Right-click a pleat for Edit pleat, open / close and delete.

Slash & spread (fullness)

  1. Choose Rotate (the slash opens like a fan around the hinge) or Parallel (the side moves straight across) in the strip, or press Tab.
  2. Click the slash point on the edge that opens (e.g. the hem), then the hinge: on the sew line (e.g. the waist), or inside the piece to rotate around that point.
  3. For several slashes press +, then click the last slash point and the last hinge. The slashes are spread evenly between the first and the last.
  4. Move the cursor to the side that should move. Its distance from the slash line is the opening, shown next to the cursor (Shift rounds it). Click to apply, or right-click for a Uniform opening, First → last openings, or an opening at the hinge as well.

Right-click a slash line for Edit openings (the change is shown before OK) or Delete, which puts the outline back exactly. The Inspector lets you type the opening of each slash. Dart ▸ Fullness ▸ Multi fullness still spreads several slashes along two whole segments.

W

Walk

Walk one seam along another to check that they match and to drop matching notches. See chapter 12.

Chapter 11Grading

The grading table (Ctrl+G) has one row per size, so it works the same for 4 sizes or 80: the header stays put while you scroll, the base size is marked ★ and the active size is highlighted (click a size name to make it active). The columns are the selected points, a dX / dY pair for each. With nothing selected you get every grade point of the selected piece. With one point you also get its X / Y position in every size and the other view (see below).

Two views, named for what a cell means:

  • Step into this size (incremental): the change from the size next to it toward the base. Sizes smaller than the base carry their own step, usually negative, the way an AccuMark rule table shows them.
  • Total from base size (cumulative): how far the size is from the base ★.

Which sizes does my edit move?When a cell has focus, the rows it will move are tinted and the line above the table names them. A step edit moves that size and every size further from the base (changing L moves L, XL and 2XL). A total edit changes that size only. The button Edit L only next to the warning switches to the total view for that cell. Moving a point on the sheet with the L size active also changes L only.

Typing. Arrow keys move between cells (← and → once the caret is at the edge of the text). Enter saves and goes down one size (Shift+Enter up), Tab goes to the next cell, Esc undoes your typing. Decimals and fractions both work (1 1/8, 9/8). To bring values in from Excel, copy a column (or a block of dX and dY columns), click the first size's cell and press Ctrl+V. The values fill consecutive size rows, the base row is skipped, and the paste is one undo step.

Smart fill and size breaks

Type values in only a few rows, for example the first step and the last size. Typed cells get a dot. Then pick a method and press Fill:

MethodWhat it does
Equal stepsThe same step for every size on that side of the base. One typed total at the last size is spread evenly.
InterpolateStraight lines between the typed totals; between typed steps, the step itself ramps (a grade that grows with the size).
Repeat stepEach typed step repeats outward until the next typed one.
Split by breakThe change up to each size break is shared evenly by the sizes in between, as in an AccuMark rule table. Click the ◆ next to a size to make it a break.

A side of the base where you typed nothing keeps its values. Next to the table, the nest preview draws the point's path through every size and redraws as you type, before you press Enter.

Grade rules

Grade ▸ Grade rules (rule library)… (Shift+Alt+R) works like an AccuMark rule table, with a few short cuts:

  1. + Library makes a rule table for the active size line. + Rule, From point or From contour fills it with numbered rules.
  2. Rules are chips (#12 Side hem). Click a chip to edit it: same rows-per-size table, views, Smart fill and breaks as above. Every point linked to the rule follows each edit (Modify Rule / Edit Rule Delta).
  3. To apply a rule, drag its chip onto a point, double-click it to apply it to the selected points, or select points on the sheet and just type the rule number (1 2 Enter).
  4. Copy rule (Copy Table Rule, optionally flipped in X or Y), Rename, Delete (linked points keep their values), Detach.

Grade ▸ Rule badges on grade points (Shift+Alt+B, or # in the grading table) puts a tag next to every grade point: blue 12 = follows rule 12, amber 12* = linked but edited by hand, green g = its own grading, no rule, grey 0 = not graded. Editing a linked point in the grading table keeps the link, so you can see it is now "edited".

Grade by measurement

Make the grading fit a spec chart instead of working out each step yourself. Grade ▸ Grade by measurement…, or Grade to spec… in the Measure window:

  1. Measurement: one you made with the Measure tool, e.g. front hem + side seam to the underarm (open, or kept with OK).
  2. Points that move: select them (e.g. side-seam hem and underarm) and click Use selection. Choose the direction (X, Y or an angle). A weight per point of −1 moves it the opposite way, 0.5 half as far.
  3. Spec: paste the spec-chart column into the Spec cells (one row per size). Spec = the measurement or change from the base size. Use a factor of 0.5 when the pattern is half of the body measurement.
  4. Preview solves without changing anything. Apply writes it as one undo step. The table shows now / after / residual per size: green means it hits the spec within 0.01 mm. On curves the residual shows what is left. The base size is never changed: if its residual is not 0, the base pattern itself is off spec.

Chapter 12Measure and check

Measure Line: add up lines in every size

Press M. As in AccuMark Measure ▸ Line Length, every line you click is added up: L1 + L2 + L3 = total, in every size at once. A line is one piece of a seam or internal line between two grade points (points made with Cut Point count).

  1. Move over the pattern: the line under the cursor lights up and shows its length. Click it. It is labelled L1 on the sheet and the Measure window opens at the right.
  2. Click more lines: L2, L3, … The window has one row per size (it scrolls for 80 sizes) with a column per line, the total Σ, and Δ, the change from the previous size.
  3. Click a picked line again to take it out. Backspace removes the last one. Shift+click takes every line from the last one up to the clicked one. Hold Alt to measure the cut line instead of the sew line (labelled ✂), or switch Cut line on in the tool strip.
  4. Enter or right-click = OK: the measurement goes into the list in the window, where you can rename it ("Front armhole"), reopen it, copy it for Excel (Copy, one row per size) or use it for Grade to spec. Esc cancels.

Compare. Click a line on another piece while a measurement is open (or Ctrl+click to force a new group on the same piece): a second group B starts. The window then shows Σ A, Σ B and the difference B − A in every size (the button flips it to A − B). Type a target ease and a tolerance: each size turns green if it is within tolerance, red if not. Example: A = front armhole + back armhole, B = sleeve cap, target ease 15 ± 3 mm. Name a group by typing in its chip.

The Measure box in the window switches between length along the line, straight distance, dX only and dY only. In nested view (Alt+N) you can click the outline of any size shown. Each row always uses that size's own pattern.

Chapter 15Troubleshooting

The browser closed and I had not saved

Open ProwdCAD again in the same browser. It offers to restore the last auto-backup (made every 30 seconds). Choose Restore.

Dragging a point does nothing, it draws a box

That is the Select tool: it only selects (a drag is a selection box). Press G for Move Point, Shift+G for Move Line or Ctrl+Shift+G for a piece. If you really want to drag points in Select, turn on Edit ▸ Allow drag-move in Select; it moves only what you grab.

I moved one point and the points next to it moved

Their stored positions did not change. Curve points without their own grading follow their neighbouring grade points in the other sizes (the hollow circles; Nested view shows it best), and the curve through a moved point re-shapes. While you drag, the old curve is drawn dashed and those points are marked "follows". Pin them with Point ▸ Pin curve point, or move them yourself with Move Point ▸ Single. An internal point marked "connected" follows on purpose (Piece ▸ Connections).

I cannot move a point of an internal line

The line is locked to the outline (padlock on the line, dashed ring on the end). Move the outline and the line follows, or right-click the line ▸ Unlock internal line. To draw lines that are not locked, switch off Lock ends to outline in the Internal line tool's strip.

Move Point grabs the wrong one of two points on top of each other

The selected point wins, then the sew-line point. Select the one you want first (in Select, click and press Tab until the status bar names it), then press G.

My exported PDF or DXF has only one piece

When a piece is selected, the export dialog's Pieces box starts on Selected (the hint under it names the pieces); otherwise on All pieces. It is never carried over from your last export. Click an empty spot on the sheet first, or set Pieces to All pieces.

A menu item is grey

Hover it: the tooltip says what it needs, for example a selected point. Select that first.

I typed the value the box shows and nothing changed

In inch-fraction mode values are shown rounded to 1/16" (a dotted underline marks a rounded value; the tooltip shows the exact one). Typing the shown value, for example 3/8, now sets exactly 3/8". If nothing happens, check the cursor is not still in another box.

A shortcut does nothing

The cursor is probably still in a number box. Press Esc or click the sheet, then try again. Keys such as Ctrl+Shift+N are kept by the browser; use the key listed in Chapter 14.

Esc did not clear my selection

An Esc that closes a menu, or that comes right after another Esc that cancelled something, keeps the selection. Press Esc again.

A size looks wrong but the base size is fine

Open the grading table, switch to Total from base size, and check that size's row. Remember that a step edit of L also moves every size further from the base (the tinted rows); use the total view, or Edit L only, to change one size. Rule badges (Shift+Alt+B) show an amber * where a point linked to a rule was edited by hand.

An imported DXF has no seam allowance

When the file only has a cut line, ProwdCAD treats it as the sew line with no seam and says so in the import report. Use Seam ▸ Internal → seam if the file carried the sew line as an internal line.
